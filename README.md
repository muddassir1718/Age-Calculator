# 🌌 Chronicle Age & Time Canvas (ক্রনিকল কালপঞ্জি ও বয়স ক্যানভাস)

Welcome to the **Chronicle Age & Time Canvas** — an editorial, highly-curated, and immersive date, age, and astrological time calculator. This application computes precise age and calendar difference spans with extreme mathematical accuracy, mapping your life directly to celestial milestones, lunar calendars, seasonal experiences, and cosmic bio-metrics.

এটি একটি অত্যন্ত আধুনিক, নান্দনিক এবং ইন্টারঅ্যাক্টিভ বয়স ও কালপঞ্জি গণনাকারী ওয়েবসাইট। এখানে নিখুঁত হিসাবের পাশাপাশি আপনার জীবনের অতিবাহিত প্রতিটি সেকেন্ডকে রাশিফল, বাংলা ষড়ঋতুচক্র, চন্দ্র মাসের উৎসব (যেমন ইদুল ফিতর ও ইদুল আজহা) এবং বিভিন্ন মহাজাগতিক বিষয়ের সাথে চমৎকার অ্যানিমেশনের মাধ্যমে মিলিয়ে তুলে ধরা হয়েছে।

## 🌟 Key Features (মূল বৈশিষ্ট্যসমূহ)

### 1. **Ambient Fireworks & Celebration (আতশবাজি ও উৎসব অ্যানিমেশন)**
*   When a calculation triggers successfully, the screen erupts into a celebratory, physics-accurate HTML5 Canvas fireworks show!
*   The sparks and rocket trails match your custom color theme automatically, running at a buttery-smooth 60FPS.
*   *বয়স বা তারিখের ব্যবধান সাবমিট করার সাথে সাথেই স্ক্রিনে চমৎকার আতশবাজি ফোটার উৎসবমুখর অ্যানিমেশন ভেসে উঠবে যা আপনার নির্বাচিত কালার থিমের সাথে সামঞ্জস্যপূর্ণ।*

*   Calculates your astrological Zodiac sign dynamically.
*   Transforms the entire background of the website into an interactive, physics-based canvas representing your Zodiac's ruling chemical/natural element:
    *   **Fire 🔥 (Aries, Leo, Sagittarius):** Rising glowing embers that float upward and fade.
    *   **Earth 🍃 (Taurus, Virgo, Capricorn):** Gently rotating, falling organic leaves and pollen.
    *   **Air 💨 (Gemini, Libra, Aquarius):** Sinusoidal sideways drifting purple and cyan mist orbits.
    *   **Water 💧 (Cancer, Scorpio, Pisces):** Falling, sleek crystalline rain-droplets.
*   *ব্যবহারকারীর জন্মতারিখের রাশিফল অনুযায়ী পুরো ওয়েবসাইটের ব্যাকগ্রাউন্ড রাশিফলের উপাদান (আগুন, মাটি, হাওয়া, বা পানি) অনুযায়ী পরিবর্তিত হয়ে যাবে এবং ব্যাকগ্রাউন্ডে চমৎকার মোশন অ্যানিমেশন চলতে থাকবে।*

## 🛠️ Step-by-Step User Guide (কিভাবে ব্যবহার করবেন)

1.  **Select Calculation Mode (গণনার মোড নির্বাচন):**
    *   Choose **"Age/Time until Today"** for normal age tracking.
    *   Choose **"Custom Range"** to measure the difference between two arbitrary dates.
2.  **Input Dates (তারিখ লিখুন):**
    *   Type the Start Date (Date A) fields using the numeric keypad inputs (Day, Month, Year).
3.  **Calculate (হিসাব কষুন):**
    *   Tap the **Submit Button (Arrow Icon)**. Watch the digits cycle upwards elegantly with the counter engine as festive fireworks erupt!
4.  **Discover (অনুসন্ধান করুন):**
    *   Scroll down to explore your customized Astro-Zodiac block, Eid milestones, Bangladesh season counts, and celestial/biological metrics.
5.  **Reset/Clear (নতুন হিসাব শুরু করুন):**
    *   Tap the **Symmetric Reset Button (Rotation Arrow Icon)** to clean all fields instantly and reset active canvases.

## 💻 Developer Guide & Local Execution (লোকাল সেটআপ নির্দেশিকা)

This application is built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Motion** (Framer Motion). Follow these simple steps to run it locally on your machine:

### Prerequisites:
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Steps to Run:
1.  **Clone the Repository:**
    ```bash
    git clone <your-github-repo-url>
    cd <repo-folder-name>
    ```
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Run Development Server:**
    ```bash
    npm run dev
    ```
    Open your browser and navigate to `http://localhost:3000` or the port displayed in your terminal.
4.  **Build Code for Production:**
    ```bash
    npm run build
    ```
    This generates a optimized, lightweight production-ready bundle inside the `/dist` directory.

## 🌐 Deploying to GitHub Pages (ফ্রি গিটহাব পেজেস পাবলিশ নির্দেশিকা)

Since this app is a **Client-Side Static SPA**, you can publish and host it completely for **FREE** on **GitHub Pages**! 

### Quick Deployment Instructions:
1.  Add the `gh-pages` package to your dev dependencies:
    ```bash
    npm install -D gh-pages
    ```
2.  Open your `package.json` file and add the following scripts:
    ```json
    "homepage": "https://<your-username>.github.io/<your-repository-name>",
    "scripts": {
      "predeploy": "npm run build",
      "deploy": "gh-pages -d dist",
      ...
    }
    ```
3.  Run the deployment command:
    ```bash
    npm run deploy
    ```
4.  Go to your GitHub Repository > **Settings** > **Pages**, and make sure the source branch is set to `gh-pages`. Your beautiful interactive age canvas is now live for the world to see!
